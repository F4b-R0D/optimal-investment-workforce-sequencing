# Research Design

## Main question

What timing and scale of investment projects generate a sustainable occupational employment path while respecting labour-market and project constraints?

## Baseline pipeline

Investment → IO → NAICS employment → NOC employment → labour gaps → optimization.

## Initial decision variables

- Project start year
- Annual project expenditure
- Project phase / intensity
- Training investment, in later versions

## Candidate objective terms

- Employment volatility
- Occupational shortages
- Dependence on external/FIFO labour
- Project delay costs
- Net present value / economic output
- Unemployment or under-utilization

## Candidate constraints

- Annual budget
- Occupational labour availability
- Project precedence
- Earliest/latest project start
- Construction capacity
- Minimum/maximum annual project spending
- Training lags
